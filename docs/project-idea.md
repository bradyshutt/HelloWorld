# Voice Journal

Basic activity logging recorded through voice chat.

## Goals

- Create a simple running journal of the events of your day, like a field log.
- Enable the user to practice speaking. This trains the idea → thought → voice process, and will likely help improve speaking ability.

## Bonus

- Have the AI narrate back your day in a fun style: for example, presenting it as an epic story, but using just the details of your day.
